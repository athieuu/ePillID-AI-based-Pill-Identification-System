# ePillID - AI-based Pill Identification System

## Overview
ePillID is a machine learning and computer vision project developed using Python and Google Colab.  
The system focuses on identifying pills from images through data preprocessing, image handling, and model evaluation techniques.

## Features
- Pill image identification
- Dataset preprocessing and cleaning
- Machine learning workflow experimentation
- Model evaluation and prediction analysis
- Google Colab implementation

## Technologies Used
- Python
- Google Colab
- Jupyter Notebook
- Machine Learning
- Computer Vision
- NumPy
- Pandas

## Project Structure
- `ePillID_tutorial_colab.ipynb` — initial experimentation notebook
- `ePillID_tutorial_colab_Final.ipynb` — final implementation notebook
